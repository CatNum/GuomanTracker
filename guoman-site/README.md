# 国漫追更

## 重点

线上版本 0.2.2 提供主流平台国漫索引、邮箱验证码账号、追番和手动观看进度；当前站点为 [CloudBase 共享域名](https://guoman-d1goxm3hhb53752a4-1315191445.tcloudbaseapp.com/)，旧 EdgeOne 临时域名仅作历史记录。Stitch 悬浮侧栏与扑克牌抽取界面已于 2026-10-12 发布，包含「精准抽卡」「新番周历」「我的追番」「国漫合集」和补录入口。当前 CloudBase 环境采用 PG 共享集群；PG 用户云函数已于 2026-10-12 部署，真实邮箱会话已验证云端追番和进度保存、刷新恢复。用户已手工验证同邮箱退出重登后记录恢复，以及双邮箱追番与进度相互隔离；扫描云函数尚未接入 PG，未部署。仍不做提醒、通知、日历订阅或站内视频播放。

需要邮箱验证码登录后才能保存追番和观看进度。未配置邮箱服务时，页面仅提供合集浏览；云端请求失败会保留当前记录并允许重试。

## 一、当前收录边界

- 哔哩哔哩：完整读取当次官方国创索引 3,218 个季/作品条目，直接使用官方播放链接。官方索引可能包括动态漫与分季，不等同于 3,218 个独立 IP。
- 腾讯视频：官方动漫频道当次可读取的 11 个条目，排期未能核验的保持未知。
- 优酷：从官方频道筛选 16 个已核验国产作品；海外动画不收录。
- 爱奇艺、芒果TV：暂不可用于筛选、追番、进度或扫描。

页面仅显示可用平台的实际收录数。播放、会员、地区限制和移动端唤起能力由官方平台决定。

## 二、我的追番工作区

默认进入「精准抽卡」，按账号优先级推荐有可靠未看内容的作品，最多同时展示五张卡。
点击卡牌先选中并向上抽起，再次点击翻转打开详情；支持左右方向键、回车和空格。
卡面使用真实作品状态、平台和观看进度，不显示示例评分；
封面保留原始亮度与饱和度，仅在底部加遮罩保证文字可读，
卡组上方不再显示当前抽取目标提示。

「我的追番」独立列出所有追番，
包括暂停项、待核验项和历史不支持平台记录。爱奇艺与芒果 TV 的旧记录保留并置灰，
仍可取消追番。排序可选账号优先级或完整名称拼音；优先级提供拖动手柄和上移、下移按钮，
名称排序或筛选期间暂停顺序调整。四项统计可单击筛选，再次点击清除筛选；
推荐保持全库计算，不随列表筛选变化。

本周统计按北京时间周一零点切周，只计已发布、未延期、已发生的正片数字集号，
不以最近检查时间或扫描时间代替发布时间。三个支持平台的新补录链接
均须先确认官方节目名称才会保存并加入追番；识别失败会明确提示失败，
不新增节目、追番或监控目标，也不扣补录额度。历史名称待核验记录
重新补录时会再次识别，成功后才修复名称；失败不修改已有记录。
最新集数始终单独等待可靠核验。

「新番周历」只展示当前账号已追番作品的本周官方排期，
沿用国漫合集的海报卡片、星期筛选、平台筛选和分页。
补录记录按规范化官方链接关联目录排期，保留账号中的作品编号；
标题核验不会清空已知排期，也不会延长旧排期的有效期。
尚无可核验更新日期的追番单独列在「排期待核验」，不推测其更新星期。
合集与周历共享本次已同步的官方日历，切换页面或同步失败不会退回旧排期。
新番周历与合集的本周更新默认选中北京时间的当天星期；重新进入或清除筛选回到当天，
也可手动查看全周或其他星期。
全部作品的周历仅在「国漫合集 → 本周更新」展示。
具体日期事件优先于同日固定排期；延期明确标记，只有官方已发布事件显示「已更新」。
固定排期只显示「计划更新」，完结作品和过期固定排期不推算新更新。
手机导航保留全部入口，账号按钮可登录或展开已登录账号信息。

## 三、数据更新

首页和“同步日历”按钮通过 `/api/catalog`（目录与日历读取接口）更新哔哩哔哩官方国创日历；服务器缓存 10 分钟，失败返回最近的可用目录并明确提示。其他平台的排期为核验快照，超过 30 天后不再作为有效排期展示。

手动更新完整索引与补充平台的命令：

```sh
python3 scripts/collect-catalog.py
python3 scripts/collect-platforms.py
```

`scripts/collect-catalog.py`（国创目录采集脚本）读取官方分页索引与日期日历；`scripts/collect-platforms.py`（补充平台采集脚本）读取官方公开频道及节目网页。二者仅输出节目元数据到 `data/catalog.json`（节目元数据快照），不请求音视频文件，也不下载封面图片。

云端通过热门名单和用户补录 / 追番建立有限扫描目标。热门最多 30 条，每次最多 20 条，用户目标优先；不扫描全部目录。失败保留已知集数，失败尝试不刷新上次成功核验时间。无可靠最新集数的作品保持「待核验」。配置和算法边界见 [部署说明](../docs/deployment.md)。

追番数据由 CloudBase PG 用户云函数保存，客户端没有数据库直接读写权限。打开官网不自动完成观看；进度记录集数、这一集是否看完及暂停状态。表单提供「−」「+」按钮，每次增减一集；0 表示未开始，最新集数已核验时不能超过它。旧秒数记录读取时兼容为下一集未看完，后续保存会移除旧字段。

「我的追番」与抽卡详情提供「跳转集数」：默认填入下一集，也可输入其他正片集号，
通过已登录的用户云函数读取官方选集后，在新标签页打开该集。支持哔哩哔哩、腾讯视频与优酷；
不按数组位置猜集号，不将预告、花絮视为正片，也不自动修改已看进度。
腾讯按官网集数区间补读；优酷读取当前选集及官方末集所在区间，
官网未返回的其他区间或尚未上线的集数会明确提示，并提供官方作品页选集入口。
浏览器拦截新标签页时提供可点击的单集链接；取消查找或读取失败会关闭预留的空白页。
此功能需同时更新静态前端和 `guoman-user`（用户云函数），不需要数据库迁移。

## 四、开发

```sh
npm run dev
npm test
npm run typecheck
npm run build
npm run cloudbase:prepare
```

页面为中文响应式界面，支持名称、平台、状态与星期筛选。爱奇艺和芒果TV暂不可操作。封面为官方图片 URL；官方播放使用 HTTPS 页面链接。账户变量模板见 [.env.example](.env.example)。邮箱验证码需在 CloudBase 身份认证中开启邮箱登录及邮件代发。
