# 国漫追更

## 重点

源码版本 0.2.2：主流平台国漫索引、邮箱验证码账号、追番、手动观看进度和「现在看什么」。部署目标为 EdgeOne Pages + CloudBase；正式站点仍为 0.2.1，0.2.2 前端尚未发布。当前 CloudBase 环境采用 PG 共享集群；PG 用户云函数已于 2026-10-11 部署，真实邮箱会话已验证云端追番加载及进度刷新恢复。2026-10-12 用户手工验证同邮箱退出重登后记录恢复，以及双邮箱追番与进度相互隔离；扫描云函数尚未部署。仍不做提醒、通知、日历订阅或站内视频播放。

缺少配置时可以明确选择「本机演示」，记录只保存当前浏览器；不会登录账号或触发实际扫描。演示期间也可打开邮箱登录，验证失败时原记录保留。登录成功后读取账号云端记录；本机记录不会自动合并，仍留在当前浏览器。

## 一、当前收录边界

- 哔哩哔哩：完整读取当次官方国创索引 3,218 个季/作品条目，直接使用官方播放链接。官方索引可能包括动态漫与分季，不等同于 3,218 个独立 IP。
- 腾讯视频：官方动漫频道当次可读取的 11 个条目，排期未能核验的保持未知。
- 优酷：从官方频道筛选 16 个已核验国产作品；海外动画不收录。
- 爱奇艺：5 个已核验国漫专辑，读取页面明确公布的更新策略。
- 芒果TV：提供官方平台入口，暂未收录已确认可播放的作品。

这不是全平台全量完成声明。页面显示各平台实际收录数，缺失的平台显示补充状态。播放、会员、地区限制和移动端唤起能力由官方平台决定。

## 二、数据更新

首页和“同步日历”按钮通过 `/api/catalog`（目录与日历读取接口）更新哔哩哔哩官方国创日历；服务器缓存 10 分钟，失败返回最近的可用目录并明确提示。其他平台的排期为核验快照，超过 30 天后不再作为有效排期展示。

手动更新完整索引与补充平台的命令：

```sh
python3 scripts/collect-catalog.py
python3 scripts/collect-platforms.py
```

`scripts/collect-catalog.py`（国创目录采集脚本）读取官方分页索引与日期日历；`scripts/collect-platforms.py`（补充平台采集脚本）读取官方公开频道及节目网页。二者仅输出节目元数据到 `data/catalog.json`（节目元数据快照），不请求音视频文件，也不下载封面图片。

云端通过热门名单和用户补录 / 追番建立有限扫描目标。热门最多 30 条，每次最多 20 条，用户目标优先；不扫描全部目录。失败保留已知集数，失败尝试不刷新上次成功核验时间。无可靠最新集数的作品保持「待核验」。配置和算法边界见 [部署说明](../docs/deployment.md)。

「现在看什么」只从自己的追番中挑选已核验而尚未看完的作品，续看优先。打开官网不自动完成观看；进度仅记录看到第几集、这一集是否看完及暂停状态。表单提供「−」「+」按钮，每次增减一集；0 表示未开始，最新集数已核验时不能超过它。未看完优先继续当前集，看完推荐下一集；快捷看完按钮确认推荐的那一集。旧秒数记录自动转为下一集未看完，后续保存移除秒数。邮箱账号的追番数据由 CloudBase PG 用户云函数保存，客户端没有数据库直接读写权限；此前自动验收已验证添加追番、第 2 集看完与未看完的保存和刷新恢复，随后取消该次测试追番。用户 2026-10-12 手工验收使用另外保留的追番记录。

## 三、开发

```sh
npm run dev
npm test
npm run typecheck
npm run build
npm run cloudbase:prepare
```

页面为中文响应式界面，保留平台、名称、状态与星期筛选。封面为官方图片 URL；官方播放使用 HTTPS 页面链接，不伪造 App 协议或自动播放承诺。账户变量模板见 [.env.example](.env.example)。邮箱验证码需在 CloudBase 身份认证中开启邮箱登录及邮件代发；当前已用真实邮箱会话完成用户云函数的基本读写验收。旧微信授权回调仍保留兼容。
