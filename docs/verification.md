## 重点回归项

2026-10-12 优先级响应排查：原流程在保存排序成功后继续读取完整账号库，
页面等待两次串行云函数调用，额外库读取包含至少三次管理 SQL 请求。
优化为校验并采用服务端已确认的排序与版本，省去第二次云函数调用；排序成功不再展示提示。
保存本身的数据库网络耗时仍存在，本次未测量真实云端各段耗时，也不将冷启动归为已确认原因。

- 不同邮箱只能读取和修改各自的追番记录。
- 普通刷新核对可信 SDK 首尾账号与库归属，同步完整邮箱；旧页面保存前校验已确认账号，拒绝跨标签页会话切换后的写入。
- 重复补录规范化后的同一官方链接时复用节目和追番记录。
- 补录的每日新节目、监控和追番上限在读取官方元数据前预检，事务内再次校验并发限额。
- 未知节目名称保持待核验，不把未经官网核验的集数当成已发布。
- 只有哔哩哔哩、腾讯视频和优酷可补录、追番、打开和修改进度；取消追番仍可清理旧记录。
- 进度冲突和不确定提交结果会要求重新加载，不自动重放写操作。
- 未来排期、预告和总集数不能被当成已经发布的集数。
- 500 部全量排序只写账号统计文档；排序版本冲突、成员版本变化及增删 ABA 会拒绝旧顺序，进度更新不影响排序版本。
- 旧账号缺少统计文档时，新增节目位于原追番拼音顺序之后，顺带恢复真实成员计数。
- 本周统计覆盖北京时间周一零点切周、未来发布时间、延期、预告、花絮和完结未看边界。
- 推荐排除暂停、已追平及待核验记录；完结但有可靠未看内容仍可推荐。
- 名称排序固定覆盖 `cae`、`cba`、`苍兰诀`、`苍元图`，重名以作品编号稳定兜底。
- 扫描失败不覆盖已确认元数据，也不刷新最近成功核验时间。
