# 验证记录

## 当前业务边界

追番和观看进度只通过真实邮箱账号会话写入 CloudBase。目录补录只提交官方节目链接；已收录节目沿用目录原名，新节目在官网核验前显示待核验名称。当前可操作平台为哔哩哔哩、腾讯视频和优酷。

2026-10-12，用户通过真实邮箱会话手工验证同邮箱退出重登后记录恢复，以及双邮箱追番和进度相互隔离。前端与用户云函数的部署情况、扫描器尚未接入 PG 的限制见 [部署说明](deployment.md)。

## 自动检查

在 `guoman-site/` 目录执行：

```sh
npm test
npm run typecheck
npm run build
npm run cloudbase:prepare
```

单元测试通过隔离存储实现验证事务、身份隔离、链接去重、限额和进度冲突；这些测试不模拟真实浏览器账号会话。页面登录与跨账号隔离需使用真实邮箱会话核验。

## 重点回归项

- 不同邮箱只能读取和修改各自的追番记录。
- 重复补录规范化后的同一官方链接时复用节目和追番记录。
- 未知节目名称保持待核验，不把未经官网核验的集数当成已发布。
- 只有哔哩哔哩、腾讯视频和优酷可补录、追番、打开和修改进度；取消追番仍可清理旧记录。
- 进度冲突和不确定提交结果会要求重新加载，不自动重放写操作。
- 未来排期、预告和总集数不能被当成已经发布的集数。
- 扫描失败不覆盖已确认元数据，也不刷新最近成功核验时间。
