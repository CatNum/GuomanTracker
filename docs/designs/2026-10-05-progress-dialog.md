# 观看进度弹窗

目标：减号在集数左侧，加号在右侧，三个控件始终处于同一行。

- 延续现有深绿底与浅绿强调色，字号和内容层级保持一致。
- 桌面两侧按钮 64×64 像素，窄屏 56×56 像素，使用清晰的加减图标。
- 中间输入框占剩余宽度，集数居中，字体 28–32 像素；保留直接输入。
- 使用三列网格，手机不改成上下布局；零集禁用减号，核验上限禁用加号。
- 保留是否看完与暂停追番，错误提示仍在表单内。

配图为布局设计稿，实际页面需检查浏览器中的控件尺寸和横向位置。

验证发现本机 Turbopack 在修改样式及重启后仍返回旧 CSS；切换为与生产构建一致的 webpack 后返回当前源码样式。开发命令固定使用 webpack，避免本机预览与构建结果不一致。
