# Stitch 改版参考

## 重点

- **设计来源**：国漫追番项目 `6747398532150002614`，
  屏幕 `c79dcf27811a4c47bc00c1004b421cb1`。
- **参考文件**：[原始产品图](screen.png)与[导出 HTML](code.html)
  于 2026-10-12 下载；HTML 仅用于设计对照，不作为网站运行入口。
- **功能映射**：精准抽卡对应要看什么，我的收藏对应我的追番；
  新增新番周历，不新增偏好设置，账号和观看进度继续使用真实数据。

## 一、落地规则

采用深绿背景、悬浮折叠侧栏和彩色扑克牌舞台。
卡牌从左到右依次叠放；选中上提，再次激活翻转抽取详情。
评分等示例内容改为真实作品状态、平台和观看进度。

新番周历复用现有官方目录同步，只展示当前账号已追番作品的本周排期，
采用国漫合集同款海报卡片、筛选和分页；全部作品的周历留在合集的本周更新中。
卡组移除当前抽取目标提示，封面保持原始亮度与饱和度。
具体日期事件优先于同日固定排期，延期明确标记；
未确认实际上线的固定排期只显示计划更新。

## 二、交付边界

本次改版已于 2026-10-12 发布到现有 CloudBase 共享域名，后续直接在线上测试。
账号存储结构、个人记录和手动观看进度沿用现有实现，不新增偏好设置。
